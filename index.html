How signals are calculated

• Top 20: eligible active USDT spot pairs ranked by 24-hour quote volume (stablecoin/stablecoin and leveraged tokens excluded).
• Dip: current price compared with highest available candle high in the last 7 days. A 10%+ fall is a WATCH candidate, not an automatic buy.
• Trend: selected candle close compared with the previous candle close. 1M is approximated from daily candles because the exchange candle API does not provide a native monthly interval.
• This starter version uses public REST data and refreshes periodically. It does not place trades, connect a wallet, or provide guaranteed signals.
Safety: this dashboard uses public market data only. Never enter your KuCoin password, API secret, or passphrase here. BUY/WATCH labels are screening hints, not financial advice.
